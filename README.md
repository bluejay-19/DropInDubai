# Drop In Dubai — Hotel, Events & Attractions Booking Platform

A full-stack booking platform for discovering and booking hotels, 
restaurants, events, and attractions in Dubai. Built as a group 
university project.

## Features
- 🏨 Browse and book hotels, restaurants, events and attractions
- 🔍 Search and filter across all categories
- ❤️ Save and manage favourites
- 👤 User accounts — register, login, and manage your profile
- 📋 View, edit and manage past and upcoming bookings
- 🔧 Admin panel for platform management

## How to Run Locally

1. Install [XAMPP](https://www.apachefriends.org/) and 
   [Node.js](https://nodejs.org/)
2. Clone this repo
3. Open XAMPP Control Panel and **make sure Apache and MySQL 
   are both turned on** every time you run the project
4. Open phpMyAdmin (http://localhost/phpmyadmin) and import 
   the provided SQL file to set up the database
6. In the project folder, open the terminal and run:
```
   npm install
   npm start
```
6. Visit `http://localhost/[folder-name]` in your browser

> ⚠️ Every time you run the project, ensure Apache and MySQL 
> are running in XAMPP before starting the server. 
> ⚠️ In the terminal on VSCode, ensure you run `npm start` or `node server.js` to make
> sure all the data is retrieved properly from the backend.
